# Raw output — Episode 1

This folder is the unedited output of a real SceneProof run on the 142.8-second Chinese source episode.

- `asr_transcript.json`: 41 timestamped English translation segments from Whisper `small`.
- `frames/`: 16 extracted frames selected from uniform sampling, high scene-change scores, and the ending.
- `frame_evidence.json`: frame timestamps and extraction metadata. Chinese OCR is blank because the required `chi_sim` Tesseract pack was unavailable; the run records this limitation instead of inventing text.
- `extracted_evidence.txt`: merged audio and visual evidence timeline.
- `qa_report.json`: five evidence-linked adaptation issues generated by fitting the
  generic word/character TF-IDF alignment model to this run's supplied inputs.
- `pipeline_result.json`: complete run metadata and limitations, including the 63
  fitted documents and 4,690 learned features used for this review.

The QA outputs were regenerated with the model-driven reviewer. It contains no
show title, plot beat, character, venue, timestamp, or expected-issue catalogue;
those constraints come only from the four uploaded inputs.

The original video and extracted WAV are omitted to avoid redistributing the episode. The source page is linked from the app.
